# Viewer

This section helps you get comfortable with the viewer itself: what appears on the canvas, what each control does, and how to navigate the scene with the camera.

If you are new, start with **Viewer UI** to learn the layout (buttons, structures bar, and popout). Then continue with **Camera and controls** to learn how to focus the view, reset the camera, and save/restore camera snapshots while you explore.
