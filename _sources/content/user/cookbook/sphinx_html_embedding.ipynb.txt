    "# Sphinx HTML Embedding\n",
    "\n",
    "This notebook shows a recommended way to include interactive MolSysViewer views of your molecular systems in Sphinx-based web documentation.\n",
    "\n",
    "This workflow assumes that the `myst-nb` package is installed and that the `myst_nb` extension is enabled in your Sphinx configuration (for example, in `conf.py`: `extensions = [..., \"myst_nb\"]`).\n",
    "\n",
    "The workflow is as follows:\n",
    "1. Export the view to an HTML file, configured exactly as you want it to appear in your documentation.\n",
    "2. Create a Jupyter notebook with the story you want to tell, including the usual code to build and show the view of your molecular system.\n",
    "3. Hide the output of the cell that calls `view.show()`.\n",
    "4. Embed the exported HTML file via an `<iframe>` and hide the input cell.\n",
    "5. Build your documentation with Sphinx and check the result."
   ]

    "\n",
    "During the Sphinx build, everything under `_static/` is copied to the output `_static/` directory, so the file will be available at `_static/views/1tcd_view.html` in the final HTML site."

    "## Embed the HTML file with hidden instructions\n",
    "\n",
    "The function `molsysviewer.thirds.jupyter.load_html_in_notebook` embeds the HTML file written for our molecular system as a new cell containing an `<iframe>`.\n",
    "\n",
    "To avoid showing this trick publicly in your Sphinx documentation, hide the input code of the cell that calls this function. With the following cell selected, click on the gear icon (\"Property Inspector\") to open the **Common tools**, add the cell tag `remove-input`, and make sure it is enabled for your `load_html_in_notebook` cell.\n",
    "\n",
    "When Sphinx builds the documentation (with `myst_nb`), any cell tagged with `remove-input` will keep its output (the embedded iframe) while hiding the corresponding input code block in the rendered HTML.\n",
    "\n",
    "The relative path used here, `../../../_static/views/1tcd_view.html`, is resolved from the location of the final HTML page corresponding to this notebook: it walks up three directories from `content/user/examples_and_recipes/` to the documentation root, then points into `_static/views/` where the exported HTML file was placed."
