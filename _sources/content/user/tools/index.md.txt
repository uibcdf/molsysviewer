# Tools

`molsysviewer.tools` is the home for advanced viewer-safe operations that go beyond the small core API of `MolSysView`.

Use this section when you want functions that:

- combine existing views,
- build a new viewer from several inputs,
- or later perform higher-level analysis/build operations without inflating `MolSysView` itself.

Start with `basic`, which contains the first pure composition helpers.
