# Unit 13: Advanced Sectioning & Clipping

## Objectives
Control the environment and 'slice' through molecules.

## Code
```python
view.scene.add_section(point=[0,0,0], normal=[0,0,1])
view.scene.set_clip_planes(near=20)
```

## Comments
Sectioning allows you to see inside a protein. Clipping manages what the camera renders.

## Teachings
Master Z-clipping and world-space sections to reveal hidden features in dense molecular systems.
