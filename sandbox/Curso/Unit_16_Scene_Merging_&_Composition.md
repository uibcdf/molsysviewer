# Unit 16: Scene Merging & Composition

## Objectives
Combine multiple independent viewer sessions.

## Code
```python
from molsysviewer.tools.basic import merge
merged_view = merge([view1, view2])
```

## Comments
Merging imports regions, shapes, and styles from several views into a single unified scene.

## Teachings
Master scene composition. You can build parts of a scene in separate views and then fuse them together.
