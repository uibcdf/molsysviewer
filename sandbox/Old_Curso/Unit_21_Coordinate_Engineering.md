# Unit 21: Coordinate Engineering

## Objectives
Mutate the structure programmatically and see instant updates.

## Code
```python
coords = view.get_coordinates()
view.set_coordinates(coords + 0.1)
```

## Comments
Directly editing coordinates allows for interactive modeling and visual perturbation analysis.

## Teachings
The structure is not static. You can 'push' new data to the GPU in real-time.
