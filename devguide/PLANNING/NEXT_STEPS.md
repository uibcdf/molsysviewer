for the main roadmap.

As of the current development cycle, most “phase 0/1” tasks live in
`PLANNING/ROADMAP.md` and in GitHub issues/PRs. This file is intentionally
lightweight and can be used as a scratchpad for very near-term work.

Examples of the kind of items that belong here (update as needed):

- [ ] Small UX tweaks in the on-canvas controls (placement/autohide).
- [ ] Incremental tests for specific shapes or loaders discovered while
      reviewing issues.
- [ ] One-off docs cleanups that are too small for the main roadmap.

When tasks become stable or long-term, promote them into `ROADMAP.md`.
