# Independent audit of pre-1.0 Phases 5, 6, 8, 9 and Phase 10 persistence

**Date:** 2026-08-09. **Result:** Phases 5, 6, 8 and 9 closed; the Phase 10
persistence slice closed. Phase 7's visible Qt observations remain open.

The audit read implementation, tests and durable evidence before mutating one
guard per mechanism. Every mutation was restored from a file copy, never with a
destructive Git command.

| Slice | Mechanism mutated | Mutation | Test that failed |
|---|---|---|---|
| 5 | popup fallback preserves endpoint lifecycle identity | close the popup endpoint manager after fallback | `test_a_popup_targeted_stream_fallback_cancels_and_loads_the_same_endpoint` |
| 6 | closing one endpoint cannot clear another endpoint's bundle | make `EndpointTransferRegistry.close` clear all popup state | `test_closing_one_endpoint_removes_its_complete_bundle_only` |
| 8 | scene-history byte budget evicts observably | disable `_enforce_byte_limit` | `test_history_byte_budget_discards_oldest_checkpoints_observably` |
| 9 | current architecture docs cannot restore obsolete Qt JSON-only claims | add `Qt keeps the JSON path` to the current data-plane document | `test_current_architecture_documents_do_not_restore_completed_work_as_pending` |
| 10 persistence | exact watermark, implicit-layer provenance and atomic replacement | remove each guard independently | the corresponding exact-round-trip or atomic-save regression failed |

After restoration, the combined focused audit set passed 59 tests. The Phase 8
small worker was rerun at 2,882 atoms and one structure: serialization 32.53 ms,
registration 32.42 ms, metadata 0.2679 MiB and binary coordinates 0.033 MiB. The
result is coherent with the retained representative-scale report; no new
performance claim is inferred from one sample.

No implementation defect was found in these slices. This audit does not close
the two Phase 7 observations: this executor has no accessible visible desktop,
and `DISPLAY=:0 glxinfo -B` was rejected by X authorization from its SSH-only
session. The required ten visible reloads and camera/zoom observation must run
on the real Qt/GPU workstation.
