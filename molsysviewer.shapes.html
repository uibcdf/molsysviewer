molsysviewer.shapes.rings module#

class molsysviewer.shapes.rings.Rings(view)[source]#

Bases: object

API to build flat rings (circles) perpendicular to a per-ring axis.

Generic primitive — any consumer that needs orthogonal rings along an axis: HOLE-style pore clearance profiles, channel bottleneck rings, gate/mouth accents, etc. Each ring is a thin closed tube of thickness swept around a circle of the given radius centered at center in the plane normal to normal. The render reuses the channel-tube geometry on the frontend.

add_rings(*, centers, normals, radii, thickness=None, colors=None, color_by=None, color_mode=None, values=None, palette=None, color_map=None, segments=None, alpha=None, tag=None, layer_tag=None, name=None, skip_digestion=False)[source]#

Render one ring per (center, normal, radius).

Parameters:

  • centers (Iterable[Sequence[float]]) – Per-ring center (length, Å), axis (direction, unitless) and circle radius (length, Å). Must be the same length N.

  • normals (Iterable[Sequence[float]]) – Per-ring center (length, Å), axis (direction, unitless) and circle radius (length, Å). Must be the same length N.

  • radii (Iterable[float]) – Per-ring center (length, Å), axis (direction, unitless) and circle radius (length, Å). Must be the same length N.

  • thickness – Tube thickness of the ring (Å), scalar or per-ring. Defaults to a thin ring relative to its radius.

  • colors (Sequence[int] | None) – Per-ring color (or a single color for all).

  • color_map (Sequence[int] | str | None) – Scalar coloring: map values (e.g. clearance radius) through a palette. color_by selects the mode (e.g. 'clearance').

  • segments (int | None) – Circle resolution (number of straight chords per ring).

Add one or more spheres to the scene.

When center is a single 3-D point the call returns a single Shape.

When center is a sequence of points a batch is created: all spheres share one layer_tag so they can be shown/hidden/deleted as a group, while each sphere keeps its own unique tag. The return value is a list of Shape objects.

Parameters:

  • center – Single [x, y, z] point (with puw units) or a list/array of such points for a batch call.

  • radius – Radius scalar or a list of radii (one per sphere in a batch).

  • color (int) – Color as 0xRRGGBB integer (scalar or list).

  • alpha (float) – Opacity 0–1 (scalar or list).

  • tag (str | list | None) – Single tag (single sphere), list of tags (batch 1:1 mapping), or prefix string (batch generates prefix1, prefix2, …). Defaults to auto-generated shapeN names.

  • layer_tag (str | None) – Shared layer tag for the batch. Defaults to the single sphere’s own tag (single) or a new auto-generated layerN (batch).

  • selection (str | None)

  • atom_indices (Sequence[int] | None)

API to build flat rings (circles) perpendicular to a per-ring axis.

Generic primitive — any consumer that needs orthogonal rings along an axis: HOLE-style pore clearance profiles, channel bottleneck rings, gate/mouth accents, etc. Each ring is a thin closed tube of thickness swept around a circle of the given radius centered at center in the plane normal to normal. The render reuses the channel-tube geometry on the frontend.
