# Developer Hub Governance Directives (`docs/content/developer/AGENTS.md`)

This file defines governance rules for all developer documentation under `docs/content/developer/`.

---

## 🎯 Developer Hub Principles

1. **Source of Truth:** Developer documentation is the authoritative technical reference for MolSysViewer architecture, API design, JS/Python protocols, and release workflows.
2. **Never Edit Generated Files:** Re-emphasize that generated JS outputs (`molsysviewer/viewer.js`) and static views are build artifacts and must never be edited manually.
3. **No Mocks in Core Architecture Tests:** Internal architecture examples should reflect real behavior and demo systems (`dialanine`, `pentalanine`, `tctim`, `chicken_villin_HP35`).
