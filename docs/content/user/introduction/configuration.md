# Configuration

MolSysViewer exposes a small set of user-facing configuration options.

This page is a placeholder.

It will include:
- how to control the default on-canvas UI (`molsysviewer.config.show_controls`, `molsysviewer.config.autohide_controls`),
- how to place the controls (`molsysviewer.config.controls_position`, `molsysviewer.config.controls_position_fullscreen`),
- and how to load user presets (`molsysviewer.config.load_user_presets`).
