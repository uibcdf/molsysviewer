# Overlays

Overlays are visuals added on top of the molecular system (shapes, annotations, etc.).

Use these concepts together:

Tags
: Lightweight grouping label used by many APIs (for example, shapes). Tags are great when you want to clear only part of the scene.

Layers
: A higher-level grouping mechanism. You can hide/show/delete a whole layer by tag.

Regions
: Structural subsets (selections) with their own representations. Regions are not overlays; they are part of how you draw the molecular system.
